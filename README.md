# Scent Memory — strona do GitHub Pages

## Publikacja
1. Rozpakuj paczkę.
2. W swoim repozytorium GitHub otwórz `Add file` → `Upload files`.
3. Prześlij pliki `index.html`, `style.css`, `script.js`, `prywatnosc.html` **i cały folder `images`** do katalogu głównego repozytorium (nie przesyłaj nadrzędnego folderu). Jeśli już istnieją, potwierdź ich zastąpienie w commicie. Nie usuwaj repozytorium ani jego konfiguracji.
4. Kliknij `Commit changes`.
5. W `Settings` → `Pages` wybierz `Deploy from a branch`, gałąź `main`, folder `/(root)` i zapisz. Poczekaj na wdrożenie.

## Formularz
Formularz działa przez https://formsubmit.co i wysyła na `kontaktscentmemory@gmail.com`. Pierwsze wysłanie zwykle wymaga potwierdzenia aktywacji w e-mailu na tej skrzynce. Przed aktywacją wykonaj wysyłkę testową, sprawdź folder Spam i potwierdź nadawcę. W przypadku zmiany usługi dostosuj `action` w `index.html`.

**Uwaga:** To zewnętrzna usługa, a przesyłane dane trafiają do jej infrastruktury. Przed publikacją biznesową uzupełnij `prywatnosc.html` (wskazane miejsca w nawiasach kwadratowych), zweryfikuj zgodność z RODO i sprawdź warunki dostawcy. Nie publikuj jako finalnej polityki bez tych zmian.

## Zdjęcia — NOWA WERSJA
W folderze `images/` są cztery **różne** fotografie wygenerowane na potrzeby strony, dobrane jako spójna stylistycznie seria (ciepłe światło, ciemny stół, jasne karty, delikatne złoto). Nie są to zdjęcia rzeczywistych realizacji marki.
- `stanowisko-detal.jpg` — główne zdjęcie na stronie (hero)
- `flakony-zblizenie.jpg` — flakony w galerii
- `blottery-zblizenie.jpg` — karty zapachów w galerii
- `akcesoria-zblizenie.jpg` — dłoń i blotter w galerii

Przy aktualizacji istniejącej strony **zastąp wszystkie cztery pliki JPG**, bo ich nazwy zostały zachowane, ale zawartość jest nowa. GitHub Pages może pokazać zmianę po kilku minutach; w przeglądarce użyj odświeżenia bez pamięci podręcznej.

## Inne
- Na stronie nie podajemy cen. Każde wydarzenie podlega indywidualnej wycenie na podstawie liczby uczestników, miejsca, czasu i personalizacji.
- Menu mobilne i automatyczny rok w stopce są obsługiwane przez `script.js`.
- Strona działa na statycznym GitHub Pages — bez serwera i bez instalowania bibliotek.
